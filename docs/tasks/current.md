## v2.2 缺陷与安全修复（2026-11-01 完成，部分延后）

- 背景：对系统做一次独立的完成度核查与 Bug/安全扫描。结论是主干闭环真实可用，但发现 3 类必须修的问题：成绩正确性（AB 卷满分口径、阅卷状态竞态）、安全（题目详情越权、角色变更与令牌撤销不即时、JWT 回退密钥）、考生端答案丢失。扫描同时确认多处文档声明与实现不符。
- 影响面判断：AB 卷满分与阅卷竞态会造成真实考试成绩事故（及格率恒 0、成绩永久发不出去），属最高优先。
- 并行说明：本轮与「媒体上传 / 通知通道 / 监考中心」另一条工作线同时在同一工作区推进，按"只提交自己的文件、先做不撞车的部分"执行。考生作答页（`AttemptPage.tsx`）在该线正在改写，Task 45 顺延；监考文案因该线已补上切屏/全屏/断线上报，原"虚假宣传"前提消失，Task 46 的文案部分不再需要改。

### 做什么

1. **AB 卷满分按分组统计**：快照新增 `group_totals`，`TotalFor(group)` 取该考生分组满分；`buildSnapshot` 对 `ab` 要求 A/B 两组各有题；考试分析、及格线默认值、分数段、成绩导出的满分/得分率分母全部改为按答卷所属分组计算；随机卷按单组处理保持原值。
2. **阅卷状态竞态**：`SubmitReview` 先锁 `attempts` 行再锁 `review_tasks`（与 `SubmitAttempt` 统一锁序），使"最后一题评完"的 `submitted→graded` 判定串行化；`PublishScores` 增加自愈更新，把历史上已卡在 `submitted` 且无待阅任务的答卷纠正为 `graded`。
3. **孤儿阅卷任务**：替换阅卷名单时，把已不再名单内的 `pending/in_progress` 任务回收为未分配（回公共池），避免无人可提交导致整场考试发不出成绩。
4. **题目详情越权**：`GetQuestion/UpdateQuestion/PublishQuestion` 接入与列表一致的 `bankVisibility`，越权统一 404，堵住"按 UUID 读他人 personal 题库标准答案"。
5. **令牌即时失效**：`users.security_stamp`（迁移 0011），角色/数据范围/密码/停用/登出时提升；`authenticate` 比对令牌签发时间，早于 stamp 即拒绝；`requireRoles` 改用请求级 `actor.Role` 而非 `claims.Role`；监考 WebSocket 握手同样重载账号并校验 stamp。
6. **JWT fail-closed**：仅 `APP_ENV=dev` 允许使用内置开发密钥，`test`/`release` 缺 `JWT_SECRET` 一律拒绝启动；密钥长度下限校验。

### 为什么没有重启服务

`server/internal/httpapi/static.go` 的静态服务用 `http.Dir(root)` 每次请求从磁盘读取，`index.html` 走 `Cache-Control: no-cache`、`/assets/*` 走 immutable 长缓存（文件名带内容哈希）。因此替换目录后立即生效，无需重启 systemd，也就没有服务中断。

## v0.6 数据范围、认证加固与安全测试（2026-11-01 完成）

### 做什么

5. 刷新令牌：`refresh_tokens` 表（哈希存储、轮换、吊销、重用检测），登录下发、`/auth/refresh` 轮换、登出吊销；前端 401 自动续期一次后重试。
6. 前端分包：路由级懒加载 + vendor 手动分包，主包体积下降。
7. 测试：新增 `scripts/security_check.mjs`（注入/越权/篡改/限流/令牌轮换/答案泄露）与 `scripts/smoke_ui.mjs`（全路由爬取 + 控制台零报错）。

- 阅卷：`exams.rules.review_mode`（single/double，默认 single）+ `review_threshold`（未配置按满分 20%）；一评/二评分差 ≤ 阈值取平均，> 阈值生成三评仲裁，仲裁分即为最终分；轮次任务按当前待评任务数最少自动分配，并排除同一题前一轮的评阅人；未配置阅卷教师时留在公共认领池。
- 范围：`exam_proctors` 为空时该考场对所有监考员开放，配置后即收紧；`reviewer` 仅见分配给自己的任务（未分配任务对全部阅卷教师可见），`exam_admin`/`org_admin` 不受限。
- 通知：考试发布通知全部考生、成绩发布通知对应考生，`status='sent'`；`(user_id, source_type, source_id)` 去重，重复发布不重复发送。
