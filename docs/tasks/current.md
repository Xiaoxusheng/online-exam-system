## 前端 UI 去 AI 味精修（进行中，2026-10-31，与后端 v0.3 并行，只改 web/）

- 背景：v0.2 的视觉升级引入了典型 AI 审美：工作台深蓝渐变 hero + 营销数字、全站彩虹 accent 彩色图标、玻璃拟态、路由切换飞入动画、无数据支撑的状态灯（"实时"/"界面预览"/"骨架已就绪"）。用户要求更现代、更像成熟企业产品。
- 目标：不改业务逻辑与信息架构，按「克制 + 秩序 + 层级」全站降噪。

### 做什么

1. 设计 token 收敛：圆角 8/12、去发光按钮阴影、控件高 36、顶栏 60、背景中性化。
2. 去装饰：删工作台渐变 hero 与营销数字、内容区光斑、路由飞入动画、404 渐变字与光斑、登录页浮动光球/网格/交错动画、毛玻璃顶栏。
3. 去彩虹：蓝/紫/粉/青/橙 accent 收敛为品牌蓝 + 中性灰 + 语义色；统计卡改纯排版数字；快捷入口图标统一。
4. 去假状态：删"实时"pill、侧栏"界面预览"绿点、模块页"骨架已就绪"绿点。
5. 模块页诚实化：改为「状态说明 Alert + antd Steps + 简单能力列表」，删除 hero 与编号卡墙；moduleMeta 删除 accent/icon 字段。
6. 工作台重构：PageHeader 问候 + 概况 → 统计面板（单卡 4 栏 tabular-nums）→ 待开始考试/最近动态 → 快捷入口降噪。
7. 验证：typecheck + build + 浏览器实机（登录/工作台/模块页/404，桌面 + 移动）。

### 不做什么

- 不改路由、API、鉴权、状态管理；不碰 server/（后端 v0.3 正在并行开发）。
- 不做深色模式、不引新组件库、不改侧栏分组导航结构。

## 当前版本：v0.3 后端业务闭环（进行中，2026-10-31）

- 目标：把 `/api/v1` 下所有业务骨架接口从「空列表 / 501」变为真实实现，打通「题库 → 组卷 → 发布考试 → 考生作答 → 自动判分 → 人工阅卷 → 成绩发布 → 统计」主链路。
- 前端本轮不改，仍展示骨架页面；后续任务再接真实数据。

### 做什么

1. 组织与账号：校区、班级、用户 CRUD 与筛选；角色、数据范围、密码重置；用户归属班级/校区。
2. 题库：题库管理、题目 CRUD 与发布、按题型/难度/知识点/关键词检索、版本记录。
3. 试卷：固定卷 / AB 卷题目编排、随机卷抽题规则、提交审核与审核通过、总分校验。
4. 考试：创建考试计划、按用户或班级编排考生、AB 分组、发布时生成试卷快照。
5. 作答：开考幂等、按分组下发题目（去答案）、答案乐观锁保存、断线恢复、交卷幂等。
6. 判分：单选/多选/判断/填空自动判分（多选按规则部分分），主观题/编程题/音视频题转人工阅卷。
7. 阅卷：任务列表/详情、评分与评语、成绩合成、待阅统计。
8. 成绩：汇总、详情、发布、我的成绩、考试统计（平均/最高/最低/及格率/分数段）。
9. 监考与系统：考生事件上报、监考事件查询与处置、场次概览；通知列表与已读；审计查询；系统概览。
10. 测试：判分单元测试 + 全链路 API 脚本（含越权、版本冲突、交卷幂等断言）。

### 不做什么（v0.3 明确排除）

- WebSocket 实时推送（`GET /proctor/exams/{id}/ws` 仍返回 501；前端可先用轮询）。
- 编程题隔离沙箱执行（编程题只走人工阅卷，不自动跑用例）。
- Excel 批量导入/导出、文件上传、短信/邮件真实发送、人脸核验、AI 行为检测、抓拍存储。
- 刷新令牌、登录限流、多租户隔离、证书与申诉流程。
- 前端页面接业务接口（另立任务）。

## 技术决策（已确认 2026-10-31）

- 数据库：PostgreSQL 16（本机复用 StockFlow 的 PG 实例，独立库 `online_exam`）。
- 一期范围：全量骨架 + 登录（用户选择）。
- 仓库：单仓 `server/` + `web/`。
- 端口：API 8081、Web 5174（8080/5173 被 StockFlow 占用）。
- 后端：chi + pgx + 手写 SQL，不引 ORM；JWT HS256；bcrypt cost 12。
- 前端：React 19 + TS + antd 5，主题飞书蓝 #3370FF，TanStack Query + Zustand。
